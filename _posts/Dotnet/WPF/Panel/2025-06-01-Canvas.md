# Canvas

Canvas 需要手动移动子控件来控制其位置，适合需要完全自行布置子控件的场景。它默认不会排列子控件，只提供放置控件的区域。

**按锚点设置位置**

```xml
<Canvas>
    <Button Canvas.Left="10">Top left</Button>
    <Button Canvas.Right="10">Top right</Button>
    <Button Canvas.Left="10" Canvas.Bottom="10">Bottom left</Button>
    <Button Canvas.Right="10" Canvas.Bottom="10">Bottom right</Button>
</Canvas>
```

`Panel.ZIndex` 设置子控件的叠放顺序，值较大的显示在上层。如果没有设置或值相同，后声明的控件显示在上层。

C# 

`Canvas.SetTop(UIElement, y)` 通过左上角原点设置控件的 Y 坐标。

`Canvas.SetLeft(UIElement, x)` 通过左上角原点设置控件的 X 坐标。

`SomeCanvas.Children.Add(UIElement)` 将控件添加到 Canvas。
