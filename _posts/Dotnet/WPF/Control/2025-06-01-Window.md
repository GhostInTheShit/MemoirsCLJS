# Window

本质也是一个Control

`WindowStartupLocation` 属性,出现的位置

`ContentRendered` 事件，UI刚渲染完

`ResizeMode` 可以设置为`NoResize`,这样就不能放大缩小

`WindowStyle="None"` 取消窗口样式,没有了上面的边框.

`MouseDown="MainWindow_OnMouseDown"` 没有了边框，解决拖动.
```C#
private void MainWindow_OnMouseDown(object sender, MouseButtonEventArgs e)
{
        //已经封装好了,只要鼠标按下,就能允许拖动.
        DragMove();
}
```

### 模拟对话框
`ShowDialog()` 以模拟窗口的方式打开.有返回值

>[!warning]
>只能调用一次(每次都new一个就行),必须从 UI 线程调用

`DialogResult` 可空布尔值,需要模拟`ShowDialog`打开,一旦设置true或false会触发Closing事件关闭窗口并返回值.

也可以用 `IsDefault` `IsCancel` 来简化
```xml
<!-- 按下 Enter 自动触发 -->
<Button IsDefault="True" Click="OkButton_Click">确定</Button>

<!-- 按下 Esc 自动触发 -->
<Button IsCancel="True" Click="CancelButton_Click">取消</Button>
```

调用一般在后置代码,通过`button`打开
