# Rich Text 富文本

流体系,和UI体系有所不同

自带`Ctrl+F`搜索,需要窗口有足够的空间.

`FlowDocument` 需要放到以下三个包装器里面,只读

* FlowDocumentScrollViewer
* FlowDocumentPageViewer
* FlowDocumentReader

----------------------

`FlowDocumentScrollViewer` 滚动条

`ScrollViewer.VerticalScrollBarVisibility`

-------------------------------
`FlowDocumentPageViewer` 自动分页

--------------------------
`FlowDocumentReader` 最全能的,资源消耗最大

ViewingMode - 控制初始查看模式。 默认值为Page，但如果您需要其他默认视图，则可以将其更改为Scroll或TwoPage。 除非明确禁用，否则最终用户仍可以更改此设置。

IsFindEnabled - 使您能够禁用文档中的搜索。 如果禁用，搜索按钮将从工具栏中删除。

IsTwoPageViewEnabled， IsPageViewEnabled 和 IsScrollViewEnabled - 允许您关闭阅读器的特定查看模式。 设置为false时，此模式不再适用于阅读器，并且该按钮将从工具栏中删除。

Zoom - 允许您设置默认缩放级别。 标准是100％，但您可以使用Zoom属性更改此值。

------------------
`FlowDocument` 通常只是只读的,但将其放入一个RichTextBox控件后可以编辑.默认有全选和复制.还可以`Ctrl+滚轮`放大缩小.

`IsOptimalParagraphEnabled="True"` 启用最佳段落布局.

`IsHyphenationEnabled="True"` 启用字段连字符或者断字布局

`<BlockUIContainer>` 可以让FlowDocument放入任何UI控件,原本几乎只能放和文本有关的控件，块级

`<InlineUIContainer>` 行级

----------------------------

`RichTextBox` 控件,可写控件

```C#
//不是简单的textbox,需要TextRange获得值
//rtbEditor 为Xaml创建的RichTextBox
TextRange textRange = new TextRange(rtbEditor.Document.ContentStart, rtbEditor.Document.ContentEnd);
```

----------------------------
使用后置代码创建

```Cs
FlowDocument doc = new FlowDocument();

Paragraph p = new Paragraph(new Run("Hello, world!"));
p.FontSize = 36;
doc.Blocks.Add(p);

p = new Paragraph(new Run("The ultimate programming greeting!"));
p.FontSize = 14;
p.FontStyle = FontStyles.Italic;
p.TextAlignment = TextAlignment.Left;
p.Foreground = Brushes.Gray;
doc.Blocks.Add(p);

//fdViewer为xaml创建的FlowDocumentScrollViewer
fdViewer.Document = doc;
```
