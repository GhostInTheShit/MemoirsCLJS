# TreeView

树
```xml
<TreeView>
        <TreeViewItem IsExpanded="True">
                <!-- Head可以用标签展开,放置复杂元素 -->
                <TreeViewItem.Header>
                        <StackPanel Orientation="Horizontal">
                                <md:PackIcon Kind="GreenCircle"></md:PackIcon>
                                <TextBlock Foreground="Green"> Level 1</TextBlock>
                        </StackPanel>
                </TreeViewItem.Header>
                <TreeViewItem Header="Level 2.1"/>
                <TreeViewItem Header="Level 2.2" IsExpanded="True">
                        <TreeViewItem Header="Level 3.1"/>
                        <TreeViewItem Header="Level 3.2"/>
                </TreeViewItem>
        </TreeViewItem>
</TreeView>
```
### 动态数据
从后置代码添加数据,并且设置不同数据的显示.
```xml
<TreeView x:Name="TreeView">
        <!-- 这里使用Resource而不是ItemTemplate是因为student是第二层的需要迭代继承,
        ItemTemplate只能接受一个子级,并且只能影响当前一层 -->
        <TreeView.Resources>
                <!-- HierarchicalDataTemplate是特殊的DataTemplate(子类),区别是需要指定其子集合. -->
                <HierarchicalDataTemplate DataType="{x:Type local:Teacher}" ItemsSource="{Binding Students}">
                        <StackPanel Orientation="Horizontal">
                                <md:PackIcon Kind="Family"></md:PackIcon>
                                <TextBlock Text="{Binding Name}"></TextBlock>
                                <TextBlock Text="-"></TextBlock>
                                <TextBlock Text="{Binding Students.Count}"></TextBlock>
                        </StackPanel>
                </HierarchicalDataTemplate>
                <DataTemplate DataType="{x:Type local:Student}">
                        <StackPanel Orientation="Horizontal">
                                <md:PackIcon Kind="Man"></md:PackIcon>
                                <TextBlock Text="{Binding Name}"/>
                                <TextBlock Text="_"></TextBlock>
                                <TextBlock Text="{Binding Age}"></TextBlock>
                        </StackPanel>
                </DataTemplate>
        </TreeView.Resources>
        
        <!-- 设置自动展开 -->
        <TreeView.ItemContainerStyle>
                <Style TargetType="TreeViewItem">
                        <Setter Property="IsExpanded" Value="True"></Setter>
                </Style>
        </TreeView.ItemContainerStyle>
</TreeView>
```

{

### LazyLoad

懒加载,每次需要的时候加载，而不是一次性加载  

例子:  
展开盘符文件,每次点击展开的时候加载
```xml
<TreeView Name="TreeView" Margin="10">
        <!-- 注意这里的ItemContainerStyle仅仅影响第一层TreeViewItem，内部的使用冒泡上传，所以sender始终为第一层的TreeViewItem，事件源头为e.Source -->
        <TreeView.ItemContainerStyle>
        <!-- 设置展开的处理函数 -->
        <Style TargetType="TreeViewItem">
                <EventSetter Event="Expanded" Handler="OnTreeViewItemExpanded_OnHandler"></EventSetter>
        </Style>
        </TreeView.ItemContainerStyle>
</TreeView>
```
后置代码
```C#
public partial class MainWindow : Window
{

    public MainWindow()
    {
        InitializeComponent();
        DataContext = this;

        //获取所有盘符
        var driveInfos = DriveInfo.GetDrives();
        foreach (var driveInfo in driveInfos)
        {
            //为树添加盘符item
            TreeView.Items.Add(CreateTreeItem(driveInfo));
        }
    }

    private TreeViewItem CreateTreeItem(object o)
    {
        var treeViewItem = new TreeViewItem();
        treeViewItem.Header = o.ToString();
        treeViewItem.Tag = o;
        
        //添加一个伪项,用户不会看到.
        treeViewItem.Items.Add("Loading...");
        return treeViewItem;
    }

    private void OnTreeViewItemExpanded_OnHandler(object sender, RoutedEventArgs e)
    {
        //e.Source为真正触发的对象,sender为接收到的那个对象
        var treeViewItem = e.Source as TreeViewItem;

        //检测是不是那个伪项
        if ((treeViewItem.Items.Count==1)&&(treeViewItem.Items[0] is string))
        {
            //删除伪项
            treeViewItem.Items.Clear();
        
            DirectoryInfo expandedDir = null;

            //如果是盘符则转换为根目录并且赋值
            if (treeViewItem.Tag is DriveInfo)
                expandedDir = (treeViewItem.Tag as DriveInfo).RootDirectory;
                
            //如果是目录则赋值
            if (treeViewItem.Tag is DirectoryInfo)
                expandedDir=(treeViewItem.Tag as DirectoryInfo);
        
            try
            {
                //得到里面的所有子目录
                foreach (DirectoryInfo subDir in expandedDir.GetDirectories())
                {
                    //添加item到树
                    treeViewItem.Items.Add(CreateTreeItem(subDir));
                }
            }
            catch (Exception exception)
            {
                Console.WriteLine(exception);
                throw;
            }
        }
    }
}
```
