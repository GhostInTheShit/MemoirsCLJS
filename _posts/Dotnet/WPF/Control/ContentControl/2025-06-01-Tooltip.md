# Tooltip控件，ToolTipService类

鼠标悬停的时候给予提示

可以作为属性直接使用
```xml
<Button ToolTip="Click me">Button</Button>
```

可以用布局控件放置多个控件,可以放置图片.
```xml
<Button Content="Button">
    <Button.ToolTip>
        <StackPanel>
            <TextBlock FontWeight="Bold">Open file</TextBlock>
            <Border BorderBrush="Silver" BorderThickness="0,1,0,0" Margin="0,8" />
            <TextBlock FontStyle="Italic">Press F1 for more help</TextBlock>
        </StackPanel>
    </Button.ToolTip>
</Button>
```

如果要设置ToolTip属性
```xml
<Button Content="Button">
    <Button.ToolTip>
        <ToolTip Placement="Center">
            <TextBlock>Click to open a file</TextBlock>
        </ToolTip>
    </Button.ToolTip>
</Button>
```

ToolTipService是个附加属性.要写在触发ToolTip的控件上
```Xml
<Button ToolTipService.ShowDuration="1000" ToolTip="Click me" Content="Button"/>
```
