# Menu

菜单
```xml
<DockPanel>
        <Menu DockPanel.Dock="Top">
                <MenuItem Header="_File">
                        <MenuItem Header="_New" Click="MyMethod"></MenuItem>
                        <Separator/>
                        <MenuItem Header="_Exit"></MenuItem>
                </MenuItem>
                <MenuItem Header="_Tools">
                        <MenuItem Header="Manager">
                                <MenuItem.Icon>
                                                <Image Source=""/>
                                </MenuItem.Icon>
                        </MenuItem>
                </MenuItem>
        </Menu>
        <TextBox> something </TextBox>
</DockPanel>
```

`<MenuItem Command="Cut"></MenuItem>` 也可以放命令

### ContextMenu
右键单击出现的菜单,和Menu差不多，都是继承MenuBase类.
```xml
<StackPanel>
        <Button Content="Button">
                <Button.ContextMenu>
                        <ContextMenu>
                                <MenuItem Header="Menu1"></MenuItem>
                        </ContextMenu>
                </Button.ContextMenu>
        </Button>
</StackPanel>
```

或者使用后置代码  
放到资源里面
```xml
<Window.Resources>
    <ContextMenu x:Key="cmButton">
        <MenuItem Header="Menu item 1" />
    </ContextMenu>
</Window.Resources>
<Grid>
    <Button Content="Click me!" VerticalAlignment="Center" HorizontalAlignment="Center" Click="Button_Click" />
</Grid>
```

```c#
private void Button_Click(object sender, RoutedEventArgs e)
{
    ContextMenu cm = this.FindResource("cmButton") as ContextMenu;
    //菜单的目标位置
    cm.PlacementTarget = sender as Button;
    cm.IsOpen = true;
}
```
