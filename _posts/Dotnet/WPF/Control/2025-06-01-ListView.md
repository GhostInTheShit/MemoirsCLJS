# ListView

继承于ListBox,有`GridView`专属控件,显示和布局已经设置的很好,不需要写template.
```xml
<ListView x:Name="ListView">
        <ListView.View>
                <GridView>
                        <GridViewColumn Header="Name" DisplayMemberBinding="{Binding Title}"/>
                        <GridViewColumn Header="Name" DisplayMemberBinding="{Binding Completion}"/>
                </GridView>
        </ListView.View>
</ListView>
```
`GridViewColumn` 包括标头和列.如果要修改标头`Style`,名`GridViewColumnHeader`
`GridViewColumn` 也有一个`CellTemplate`属性,用`DataTemplate`修改模板.

`ICollectionView` 在视图的列表,可以提供分组排序等功能并且不影响原始数据.ListView主要围绕这个属性.

### 分组

```xml
<Window.Resources>
        <!-- CollectionViewSource是个特殊的集合,支持分组，而且不污染源数据 -->
        <CollectionViewSource x:Key="cvs" Source="{Binding myItems}">
                <!-- GroupDescriptions设置分组信息 -->
                <CollectionViewSource.GroupDescriptions>
                    <PropertyGroupDescription PropertyName="Sex"/>
                </CollectionViewSource.GroupDescriptions>
        </CollectionViewSource>
</Window.Resources>
<DockPanel Margin="10">
        <ListView x:Name="ListView" ItemsSource="{Binding Source={StaticResource cvs}}">
                <ListView.View>
                        <GridView>
                                <GridViewColumn Header="Uid" DisplayMemberBinding="{Binding Uid}"/>
                                <GridViewColumn Header="Age" DisplayMemberBinding="{Binding Age}"/>
                        </GridView>
                </ListView.View>
                
                <!-- 为每个组设置模板 -->
                <ListView.GroupStyle>
                        <GroupStyle>
                                <GroupStyle.HeaderTemplate>
                                        <DataTemplate>
                                                <!-- 这里绑定的是分组列表里面的Name,也就是组的值 -->
                                                <TextBlock Text="{Binding Name}"></TextBlock>
                                        </DataTemplate>
                                </GroupStyle.HeaderTemplate>
                        </GroupStyle>
                </ListView.GroupStyle>
        </ListView>
</DockPanel>
```
```C#
public partial class MainWindow : Window
{
    //公告属性
```

后置代码写法.

`CollectionViewSource`也可以写在后置

不需要暴露`myItems`了,直接设置前端的`ItemsSource`,`ListView`也不需要前端绑定.
```C#
public partial class MainWindow : Window
{
    public MainWindow()
    {
        InitializeComponent();
        DataContext = this;
        List<User> myItems = new List<User>();
        
        myItems.Add(new User() { Uid = 1, Age = 42, Sex = SexType.Male });
        myItems.Add(new User() { Uid = 2, Age = 39, Sex = SexType.Female });
        myItems.Add(new User() { Uid = 3, Age = 13, Sex = SexType.Male });

        //使用list创建一个CollectionViewSource
        var collectionView = CollectionViewSource.GetDefaultView(myItems);
        //添加分组,也可以添加其他例如排序.
        collectionView.GroupDescriptions.Add(new PropertyGroupDescription("Sex"));
        ListView.ItemsSource=collectionView;
    }
}
```
#### 组控件自定义
```xml
<ListView.GroupStyle>
        <GroupStyle>
                <!-- 设置容器风格 -->
                <GroupStyle.ContainerStyle>
                        <!-- 目标为每组 -->
                        <Style TargetType="{x:Type GroupItem}">
                                <!-- 组模板 -->
                                <Setter Property="Template">
                                        <Setter.Value>
                                                <ControlTemplate>
                                                        <Expander IsExpanded="True">
                                                                <Expander.Header>
                                                                        <StackPanel>                                                                                            <TextBlock Text="{Binding Name}" />
                                                                        </StackPanel>
                                                                </Expander.Header>
                                                                <!-- 具体内容 -->
                                                                <ItemsPresenter/>
                                                        </Expander>
                                                </ControlTemplate>
                                        </Setter.Value>
                                </Setter>
                        </Style>
                </GroupStyle.ContainerStyle>
        </GroupStyle>
</ListView.GroupStyle>
```
挺繁琐的.

### 排序

同样是设置`CollectionViewSource`.
```c#
var collectionView = CollectionViewSource.GetDefaultView(myItems);
collectionView.SortDescriptions.Add(new SortDescription("Age",ListSortDirection.Ascending));
//可以再加一个SortDescriptions,实现多个条件,从上到下为优先级.
ListView.ItemsSource=collectionView;
```

### 过滤

```C#
//获得ICollectionView
var collectionView = CollectionViewSource.GetDefaultView(myItems);

//添加过滤
collectionView.Filter = item =>
{
if (String.IsNullOrEmpty(TextBox.Text))
{
        return true;
}
else
{       
        //查找相同字符
        return ((item as User).UName.IndexOf(TextBox.Text, StringComparison.OrdinalIgnoreCase)>=0);
}
};

ListView.ItemsSource=collectionView;
```
数据刷新
```C#
private void TextBox_OnTextChanged(object sender, TextChangedEventArgs e)
{
CollectionViewSource.GetDefaultView(myItems).Refresh();
}
```
