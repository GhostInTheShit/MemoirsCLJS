# 纹理
```C#
//SpriteBatch.Begin 准备渲染
//SpriteBatch.Draw 渲染
//SpriteBatch.End 提交渲染

SpriteBatch.Begin();
SpriteBatch.Draw(_logo, Vector2.Zero, Color.White);
SpriteBatch.End();
```

>[!Warning]
>精灵批处理渲染时方法调用顺序非常重要。SpriteBatch.Begin 必须在任何 SpriteBatch.Draw 调用之前调用。完成后，必须先调用 SpriteBatch.End，才能调用另一个 SpriteBatch.Begin。如果这些方法被错误调用，将抛出异常。

`SpriteBatch.Draw(_logo, Vector2.Zero, Color.White);`

```C#
//旋转和缩放与锚点有关
SpriteBatch.Draw(
    _logo,                      // texture
    new Vector2(                // position
        (Window.ClientBounds.Width * 0.5f) - (_logo.Width * 0.5f),
        (Window.ClientBounds.Height * 0.5f) - (_logo.Height * 0.5f)),
    null,                       // sourceRectangle
    Color.White,                // color
    MathHelper.ToRadians(90),   // rotation
    Vector2.Zero,               // origin
    1.0f,                       // scale
    SpriteEffects.None,         // effects
    0.0f                        // layerDepth
);
```

>[!Warning]
>如果要启用图层深度,就要在渲染开始的时候启用sortMode.  >`SpriteBatch.Begin(sortMode: SpriteSortMode.FrontToBack)`

## 优化纹理渲染

频繁的切换要渲染的text非常消耗性能,频繁的开启渲染和关闭渲染也非常耗性能.

把所有`Texture`汇集成一个`TextureAtlas`.用`TextureRegion`来表示其中某个`Texture`.

TextureRegion
```C#
public class TextureRegion 
{
    public Texture2D Texture { get; set; }

    public Rectangle SourceRectangle { get; set; }

    public int Width => SourceRectangle.Width;

    public int Height => SourceRectangle.Height;

    public TextureRegion(){}

    public TextureRegion(Texture2D texture, int x, int y, int width, int height){}

    public void Draw(SpriteBatch spriteBatch, Vector2 position, Color color){}
}
```
TextureAtlas
```C#
public class TextureAtlas 
{
    private Dictionary<string, TextureRegion> _regions;

    public Texture2D Texture { get; set; }

    public TextureAtlas(){}

    public TextureAtlas(Texture2D texture){}
    
    public bool RemoveRegion(string name){}

    public void Clear(){}

    public static TextureAtlas FromFile(ContentManager content, string fileName){}
}
```
